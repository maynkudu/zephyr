# Research basis

Researched 2026-11-20. Preference interpretation and correction are authored workflow decisions, not experimentally established model-reliability claims.

The [WAI-ARIA APG modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) requires appropriate focus entry, contained Tab/Shift+Tab navigation, Escape handling, an accessible title and focus restoration. A redesigned visual shell preserves these responsibilities. The page was read directly; no screen-reader conformance experiment ran.

[APG structural roles guidance](https://github.com/w3c/aria-practices/blob/main/content/practices/structural-roles/structural-roles-practice.html), inspected through Context7 excerpts, recommends equivalent native HTML where possible. Consult each control's pattern rather than applying one keyboard model everywhere.

[Playwright visual comparisons](https://playwright.dev/docs/test-snapshots) document environment sensitivity. Adaptation needs a reviewed new direction and checks of preserved behavior. Similarity to the source is not an originality score.

Local design-craft, motion, verification, writing and skill-authoring guidance informed representative previews, responsive proportions, causal motion and explicit evidence. Those resources are optional companions, not bundled dependencies. Personal visual constraints apply only where the host declares them.

Scenario reviews can identify omissions. Live representative user tasks and human feedback are needed to assess how reliably an agent follows the preference workflow.
